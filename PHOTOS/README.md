# SJGAM M27 photos

24 JPEG photos documenting the console, its disassembly, boards, screen and
factory/test screens. They are documentation only: they are not part of the
firmware archive and contain no game data.

The EXIF metadata (camera model, capture dates, comments and XMP/IPTC blocks)
was removed before publication. For the 23 hardware photos, the compressed JPEG
scan data is byte-identical to the originals; only metadata segments were
dropped. `WorkDONE.jpg` is downscaled to 2000x1500 and re-encoded for README
display. The unmodified originals remain outside this repository.
