# SJGAM M27 photos

23 JPEG photos documenting the console, its disassembly, boards, screen and
factory/test screens. They are documentation only: they are not part of the
firmware archive and contain no game data.

The EXIF metadata (camera model, capture dates, comments and XMP/IPTC blocks)
was removed before publication. The compressed JPEG scan data is byte-identical
to the originals; only metadata segments were dropped. The unmodified originals
remain outside this repository.
